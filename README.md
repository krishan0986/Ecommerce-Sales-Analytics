# 📊 E-Commerce Sales Analytics
## 🌐 Live Dashboard

🚀 **View the live interactive dashboard:**  
https://ecommerce-sales-analytics-krishan.streamlit.app/
An end-to-end E-Commerce Sales Analytics project built using Python, Pandas, data visualization, and Streamlit.

The project analyzes real-world online retail transaction data to uncover insights about revenue, customers, products, countries, and purchasing behavior.

## 🚀 Interactive Dashboard

The Streamlit dashboard provides interactive analysis using country and date filters.

### Key KPIs

- 💰 Total Revenue
- 🧾 Total Orders
- 👥 Total Customers
- 🛒 Average Order Value
- 🔁 Repeat Customers
- 📈 Repeat Customer Rate

## 📈 Dashboard Analysis

The dashboard includes:

- Monthly Revenue Trend
- Daily Revenue Trend
- Top 10 Products by Revenue
- Top Countries by Revenue
- Top 10 Customers by Revenue
- Customer Purchase Behavior
- Country Filter
- Date Range Filter
- Transaction Data Explorer
- Downloadable Filtered Dataset

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
- Matplotlib
- Seaborn
- VS Code
